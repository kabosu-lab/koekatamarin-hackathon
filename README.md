# こえかた

**話すと言葉になり、本人が確かめて送ると、校内の人に届く。**

学校で働く人と生徒のためのパートナーです。パートナーは校内 SNS のナビで、話を聞いて言葉にし、共有の価値を見つけて背中を押し、関係のある人や投稿へ案内します。帰り道に話すと、パートナーが問い返し、本人も気づいていなかったコツが言葉になります。本人が確かめて送ると、校内の人に届き、返事が返ってきます。

Built with Claude: Japan 2026 の作品です。会期中（2026-11-02〜11-08）に作りました。データはすべて架空のダミーで、実在の学校、人、テナントの情報は入れていません。

## 3分で試す

Node.js 22.13 以上が必要です。API キーも Teams のアカウントも要りません。

```sh
npm ci
npm run demo
```

`http://127.0.0.1:3000` を開きます。スマホの幅が見やすいです。`npm run demo` は台本で動き、外へ通信せず、料金もかかりません。画面にも「台本で動いています」と出ます。

1. テキスト欄に「今日の授業、急に静かになった瞬間があって」と書いて Enter を押します。パートナーが問い返します
2. 「声を小さくしたんだ」と書いて Enter を押します。右のボタンが「とどける」として目立ちます
3. 「とどける」を押し、文章を確かめて、「本人として送る」を押します
4. 左へスワイプするか、右下の「みんな ›」を押し、「校内チャネル」を開きます
5. 別の人の返事を見るには、「履歴と設定」の一番下で使う人を切り替え、投稿に返信します。元の人に戻って話す画面を開くと、窓の上に返事が届きます

ほかに試せること：

- 「親に殴られている」と書くと、相談室への案内が出ます（命や安全に関わるときは、要点だけが相談室の先生に届きます）
- 「放課後に勉強会を開きたい」と書くと、足りないことだけを聞いて告知を作り、「行きます」を集めます
- 「みんな」から自習室、校内の桜を開けます

マイクを使うときは、押し続けて話し、離すとパートナーへ送ります。押したまま上へ動かすと固定になり、歩きながら話せます。ブラウザの音声認識を使うので、スマホでは HTTPS が必要です（`npm run dev:phone`、確かめ方は `docs/voice-check.md`）。

## 本物の Claude と Teams で動かす（任意）

| やりたいこと | 方法 |
|---|---|
| 本物の Claude を使う | `.env.example` を `.env` にコピーして API キーを入れ、`npm run dev`（料金がかかります） |
| 本物の Teams につなぐ | 下の手順。設定がなければダミーの Teams だけで動きます |
| すべてのテスト | `scripts/test.sh`（台本で動き、外へ通信しません） |
| ダミーのデータを最初に戻す | `npm run db:reset` |

Teams につなぐには、Microsoft Graph の委任の権限（`ChannelMessage.Send`、`ChannelMessage.Read.All` など）を持つアプリを登録し、`data/teams.json` にテナント、クライアント ID、チーム名、チャネル名を書きます。`npx tsx scripts/teams-login.ts <人物の ID>` でサインインすると、その人の投稿が本人の名前で届きます。シークレットは使いません。`data/` は Git に入りません。

返事の知らせは、時間外（土日と平日の夜など）には出しません。審査や撮影で試すときは `KOEKATA_NOTICE_ALWAYS=1` を付けて起動します（`npm run demo` には付いています）。

## Claude をどう使ったか

### 作品の中の Claude（Claude API）

| 役割 | しくみ |
|---|---|
| パートナーの話し方 | 相手のトーンに合わせ、答えを言い切らず問い返す（`src/lib/claude/persona.ts`） |
| 下書きと受け取られ方 | 話したことを投稿の下書きにし、本人が話していないことは足さない。送るのは本人だけ（`src/lib/claude/compose.ts`） |
| 命や安全の判定 | 話の中身を残さず、要点だけを相談室に伝える（`src/lib/safety.ts`） |
| 人へのつなぎ | 煮詰まったときだけ、話せそうな人を提案する（`src/lib/connect.ts`） |
| 校内の知恵を探す | Claude には候補の ID だけを返させ、本文は DB の実物を出す。経験を作らせないため（`src/lib/knowledge.ts`） |
| 夕方のまとめ | Managed Agents の係を1回だけ起こし、使えなければ手動のまとめに戻る（`src/lib/claude/evening-agent.ts`） |

### 作る側の Claude Code

- **フック**：`.claude/hooks/guard.mjs` が `.env` の読み書きと、強制 push や履歴の書き換えを止めます
- **Skill**：公開前の確認（`public-check`）と、画面を触れるようにする手順（`try-app`）
- **夜の作業**：`/loop` で、テストと公開前の確認が通ったものだけを小さくコミットします（`docs/night-loop.md`、`BACKLOG.md`）
- **サブエージェントと worktree**：独立した機能（自習室、ポートフォリオ）を別の作業ツリーで並行して作り、マージしました
- **テスト**：`scripts/test.sh` に単体テストと画面テストをまとめ、通らないものはコミットしません
- **記録**：判断の経緯は `docs/design-log.md`、前提は `BACKLOG.md` の `前提：`、レビューは `reviews/` にあります

### Claude で作ったものと、Codex を使ったところ

| もの | 作り手 |
|---|---|
| コード、テスト、文書 | Claude Code |
| 画面に出る絵（声のかたまり、動物、自習室の景色）と自習室の曲 | Claude がコードで描いたもの。画像ファイルは使っていません |
| コードのレビュー（`reviews/`） | Codex。指摘は材料として扱い、確かめてから直しました |
| 開発の途中の絵の試作 | Codex。今のアプリでは使っておらず、リポジトリにも入れていません |

## 守っていること

- 送るのはいつも本人です。AI は投稿しません
- パートナーとの話は、ブラウザのタブの中だけにあり、サーバーに残しません
- 順位や比較を作りません。休んでも減りません
- 確かめるのは人です。校内の知恵は、言葉を使われた本人が確かめてから広がります

デモの「使う人」の切り替えは、本物のログインではありません。実際の学校で使うには、ログインと権限の確認、学校の管理者の確認が必要です。
