# こえかた

Built with Claude: Japan 2026 の作品。会期中（2026-11-02〜11-08）に新しく作る。

- このリポジトリは公開。学校の実データ・実名・テナント情報は入れない（ダミーのみ）

## 動かし方

Node.js 22.13 以上が必要です（SQLite は Node 標準のものを使います）。

```sh
npm ci
npm run dev
```

`http://localhost:3000` をスマホの幅で開きます。

**API キーがなくても流れを確かめられます。** そのときは Claude の代わりに台本が答え、画面にそのことを表示します。本物の Claude で動かすときは、`.env.example` をコピーして `.env` を作り、`ANTHROPIC_API_KEY` を入れます。

| やりたいこと | コマンド |
|---|---|
| すべてのテスト（料金はかかりません） | `scripts/test.sh` |
| ダミーのデータを最初に戻す | `npm run db:reset` |
| 本物の Claude で話し方を試す（料金がかかります） | `npm run try:voice` |
| スマホの実機で音声入力を試す | `docs/voice-check.md` |

画面の上の「使う人」で、ダミーの先生や生徒を切り替えられます。デモ用の切り替えで、本物のログインではありません。学校も人物もすべて架空です。実際の学校で使うには、ログインと権限の確認、命や安全に関わるときの対応手順を学校で決めることが必要です。相談室が閉まっている夜や週末は、今は本人に外部の相談窓口を案内するだけで、学校の誰にも通知しません。この時間の対応も学校で決めてください。

分身と校舎の絵はリポジトリに入れていません。絵がない環境では、コードで描いた簡単な代わりの絵を表示します。
