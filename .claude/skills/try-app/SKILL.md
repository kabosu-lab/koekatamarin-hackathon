# 画面を触れるようにする

料金がかからず、手元の DB を汚さない形で起動する。`.env` は読み書きしない。

1. **空きを見る**：3000番が使われていないか確かめる。メモリが少ないときは、動画の書き出しと同時に動かさない。
2. **起動する**：次をバックグラウンドで動かす。DB は一時フォルダの使い捨てのファイルにする。

   ```sh
   KOEKATA_DB_PATH="<一時フォルダ>/try.db" KOEKATA_NOTICE_ALWAYS=1 KOEKATA_CLAUDE=scripted npm run dev -- --hostname 127.0.0.1 --port 3000
   ```

   `KOEKATA_NOTICE_ALWAYS=1` がないと、土日と平日の夜は返事の知らせが出ない。

3. **確かめる**：`/api/health` が 200 を返すのを待ち、主な画面（`/`、`/minna`、`/me`、`/study/room`、`/sakura`）を開く。話す画面は、書いて送り、とどけるで確認画面が出るところまで実際に動かし、画面の写真を自分の目で見る。
4. **伝える**：開く URL と、次の手順を伝える。確かめていないことは、確かめていないと書く。
   - 使う人は「履歴と設定」の一番下で切り替える
   - 「押し続けて話す」か、テキスト欄に書いて Enter で相棒へ送る。返事は台本で、本物の Claude ではない
   - 右の「とどける」で確認画面になり、直接直して「本人として送る」で送れる
   - 左右のスワイプか下の印で「履歴と設定」「みんな」へ移れる
5. **片付ける**：利用者が使い終わったらサーバーを止める。
