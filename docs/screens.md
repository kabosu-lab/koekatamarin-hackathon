# 画面の棚卸し（0-1q、2026-11-07）

すべての画面と、そこへの入口の一覧。「新しい形」は話す・タイル・会話・チップ・ボトムシートと、奥の画面の共通の外枠（`src/app/ui/PageShell.tsx`）。古い形の目印は、下の3つのタブのナビ、「デモ用：使う人」、入れ物の中だけのスクロール、文が途中で切れる箱、小さな選択の箱、別の画面に切り替わる確認画面。

全画面の写真は `e2e/screens.spec.ts` が iPhone（390×844）、iPad 縦（820×1180）、iPad 横（1180×820）で撮り、`test-results/` に残す。

## 共通にしたこと

- 下の3つのタブのナビ（`BottomNav`）と、奥の画面の下の「デモ用：使う人」（`GlobalSwitcher`）は、どの画面にも出さない。入口は左右のスワイプとページの点、ホイールのチップ、タイル。使う人の切り替えは「履歴と設定」の「設定」のタイルの中だけ
- 奥の画面は `PageShell` にそろえた：左上に「‹ 行き先」（「‹ 履歴と設定」と同じ形）、見出し、ひとこと。カードの角は 14px、余白は 12px と 16px
- 中身は下から 8px、標準のイージング（`cubic-bezier(0.2, 0.8, 0.2, 1)`）で 200ms で入る。ボタンは押した瞬間に 60ms で縮む。動きを減らす設定では動かさない（設計書 §1 原則1〜4・6・7、§2-3）
- 奥の画面では行の数で文を切らない。選ぶ箱は幅いっぱい・高さ 48px にした
- 奥の画面は画面ごとスクロールし、入れ物の中だけのスクロールはない
