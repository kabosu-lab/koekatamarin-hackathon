# 音声入力の実機確認

スマホのブラウザで、日本語の聞き取りがどこまで安定するかを人が確かめる。テストの音声認識は偽物なので、ここだけは実機でしか分からない。

マイクは HTTPS でないと使えないため、次のように開く。

```sh
KOEKATA_DEV_ORIGIN=<Mac の IP アドレス> npm run dev:phone
```

スマホを Mac と同じネットワークにつなぎ、`https://<Mac の IP アドレス>:3000` を開く（証明書の警告が出る）。

## 確かめること

端末とブラウザごとに、結果を下の表に書く。

1. 「話しかける」を押すと、マイクの許可を求められる
2. 「こんにちは」「あんた何ができるん」「私は嫌やわ」が正しく文字になる
3. 30秒ほど続けて話すと、途中で切れないか
4. 少し騒がしい部屋でも聞き取れるか
5. 「話し終わった」で止まり、話した言葉が吹き出しに残る
6. 話の途中で3〜5秒黙っても切れず、言葉がつながる（端末ごとに切れ方が違うので、テストの偽物では確かめられない）
7. 同じ言葉が二重にならない（Android の Chrome で起きやすいと言われる）
8. 3分黙るとマイクが閉じ、そこまでの言葉が残る

## 押し続けて話す、固定（実機で確かめる）

1. 短く触っただけでは聞き始めず、「押し続けて話す」と出る。途中の言葉が送られない
2. 押している間だけ聞き、離すと最後の言葉まで待ってパートナーへ送られる
3. 押したまま上へ動かすと「固定中」と大きく出る。指を離しても聞き続ける
4. マイクの許可の画面が初回の長押しを邪魔しないか
5. 片手で持って歩きながら、親指で押して上へ動かせるか
6. 固定中に「止めて送る」と「終わり」で止まり、パートナーへ送られる
7. 固定中は画面が消えないか。消えたら聞き取りが止まることが分かるか
8. 合いの手と、「どう思う？」への声の返事。読み上げを自分の声として拾わないか
9. 話す言葉が増えても、最新の行がテキスト欄に見える
