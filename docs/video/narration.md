# ナレーションの原稿（通し版・本人の声）

読みやすさを優先して、言い回しは自分の言葉に直して構いません。直すときは「使える秒数」に収めます。作品名は「こえかた」と読みます。

## 録り方

- 静かな部屋で、スマホのボイスメモで構いません。口から20cmほど離します
- 1行ごとに2秒ほど空けて、続けて録ります。言い直しは、その行の頭からもう一度読みます。あとで切り分けます
- 間違えても止めずに進めます。全部で3分もかかりません
- 少しゆっくり、話しかけるように読みます。読み上げの調子にしないほうが合います
