## 2026-11-03：「AI で解けた困りごと」から「声全体」へ

**作り手の話**

- 共有したいのは、AI で解けた困りごとだけではない。悩み、辛さ、頑張り、大会での受賞や資格の取得も共有したい
- 校内のネットワークでは、生徒同士の投稿や交流がほとんど進んでいない。ここが大きな懸念
- 探究活動や資格試験に取り組む生徒が声を上げ、お互いにいいねできる場所がほしい
- 先生にも一人一人の頑張りがあるのに、忙しくてお互いに見えず、協力もできない
- 先生の生々しい「困っている・辛い・大変」も共有し、一緒に考えて前に進むきっかけにしたい
- 普段から話しかけてもらえるアプリにする。投稿と返信の下書きを手伝い、ニュアンスを「これでいいかな」と寄り添いながら確かめる。これはデジタルデバイドの解消にもつながる
- AI にない人間の経験や、言葉にしにくい感覚を共有して人をつなぎ、学校全体で伸びる
- 生徒にとっては、社会に出る前に SNS を校内で練習する場になる。悪用しない、騙されないだけでなく、自分の頑張りを発信する力も大事
- 校内で良くない使い方があれば、生徒指導・生徒支援のきっかけになる

**設計への影響（検討中）**

- 中心を「話す → 一緒に言葉にする → 本人が送る」の1本にする。困りごと、悩み、頑張り、報告は投稿の種類の違いとして扱う
- 「先生の場と生徒の場は分ける」という前提を見直す。生徒同士の交流も主な目的に入る
- 壁打ち（本人だけ）と投稿（校内に公開）の境目をはっきりさせる。指導のきっかけにするのは、投稿されたものだけ
- 投稿の前に、Claude が受け取られ方を一緒に確かめる。これが SNS の練習になる

- 勉強会で「見られている感じがない」と止まった問題に、一緒に勉強する画面は直接答えられる可能性がある。話さなくても、誰かがいると分かるから

## 2026-11-04：背景、相棒の記憶

**作り手の話**

- みんなで育てる桜の背景に、学校を入れたい
- 見本は思いのほかよいが、少し子どもっぽい。背景は固定せず、爽やかに、時間や季節と連動させたい
- 青春時代に親しんだゲームの画面の雰囲気を取り入れたい。作り手自身につながる引き出しの一つ
- 言葉が花びらになって一輪の桜になる見せ方はよい
- 相棒には前の話を覚えていてほしい。ただ、できれば自分が公開したことから参照してほしい

**作る側の判断**

- 実在の学校の校舎の写真は、公開リポジトリの決まりと、素材の権利の決まりに触れるので入れない。提出版は架空の校舎にする。実際の学校で使うときに差し替えられるようにする
- 既存のゲームの画面はまねず、角を切ったパネルや細い線などの雰囲気だけを、きせかえの一つで取り入れる
- 相棒の記憶は2段に分ける。公開したことは長く覚えて、人の紹介にも使う。話しただけのことは、本人が「覚えて」と許したものだけ残し、本人との話にだけ使う。いつでも見られて、消せる

## 2026-11-04：声が飛ぶ、デザインの切り替え

**作り手の判断**

- 相棒の記憶は2段でよい
- 声のかたまりが飛んでいく見せ方は面白いので入れる
- Codex の絵を試しに組み込み、モダンとゲームのデザインを切り替えられるようにする

**作る側の判断**

- 飛ぶかたまりは、着くと桜の花びらになるようにして、独自の見せ方にする
- ネットに公開された校舎の写真は、絵に加工しても元の写真の権利と実在の学校の問題が残るので使わない
- Codex の絵は、使ってよいと確かめるまで公開リポジトリに入れない

## 2026-11-04：自習室を Teams から見えるように

**作り手の話**

- 生徒どうしは声も映像も絶対につながらない。相棒だけが見え、ゆるくつながる

**調べて分かったこと（`docs/research-teams.md`）**

**作る側の判断**

## 2026-11-04：インパクトと、広げ方

**作り手の話（公開用に要約）**

- 困るとすぐ人に聞くが、聞かれる人は限られている。お互いに助け合える、組織としての折れにくさを伸ばしたい
- 先生は孤独で、学校を越えて支え合う集まりも身近にない。一つの学校での取り組みを近くの学校へ広げ、全国でゆるくつながりたい
- 生徒の力も伸ばしたい。やりたいことはあるのに、自分たちで動き出せていない
- 15秒の動画は前よりよいが、ほかの作品と比べると子どもっぽい。複数の方向を試す

**作る側の見方**

- 生徒の「こうしたい」が、言葉になり、賛同が集まり、提案になる流れは、デモの強い場面になりうる
- 頼られる人への集中は、パスとアシスト、たまった知恵で和らげられる。自分で調べる入口としての Claude も役に立つ
